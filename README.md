
📥 第一步：准备工作
安装 Python：前往 python.org 下载并安装，安装时务必勾选 “Add Python to PATH”。

获取 API 凭证：

登录 my.telegram.org。

点击 API development tools。

随便填一下 App title 和 Short name，点击创建。

记下你的 App api_id (数字) 和 App api_hash (字符串)。

网络环境：确保你的 Clash 开启了 TUN 模式 (虚拟网卡模式)。对于代理用户

📦 第二步：安装必要组件
打开电脑的 CMD (命令提示符)，依次输入以下命令并回车：

DOS
pip install telethon
📄 第三步：保存脚本文件
在你的 D 盘 根目录下把提供的文件放进去命名tg_video.py预留30gb磁盘空间目录可以自定义但是要改脚本配置
第四步：启动与运行
在 CMD 窗口输入命令启动：

DOS
python D:\tg_video.py
